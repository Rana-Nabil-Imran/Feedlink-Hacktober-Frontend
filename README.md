# FeedLink AI

AI-Powered Food Redistribution

## Live Demo
https://feedlink-vert.vercel.app/

## Overview
FeedLink AI is an AI-powered food redistribution platform that connects
food donors with NGOs and receivers.

## Key Features
- AI Food Analysis
- Urgency & Priority Scoring
- Smart NGO Matching
- Food Safety Analysis
- Donation Tracking
- Notifications
- Role-Based Authentication
- Impact Dashboard
- Admin Dashboard

## How It Works

Donor
   ↓
Donation Created
   ↓
AI Analysis
   ↓
Smart NGO Matching
   ↓
Claim
   ↓
Pickup
   ↓
Delivery
   ↓
Completed
